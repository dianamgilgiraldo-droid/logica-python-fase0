# 🚀 Lógica Python - Fase 0

Repositorio dedicado a mis primeros retos, prácticas y ejercicios fundamentales de lógica de programación en Python.

## 📁 Contenido de la Fase 0
* **reto1.py**: Introducción a sintaxis, variables y operaciones básicas.
* **reto2.py**: Uso de estructuras condicionales (if, elif, else).
* **reto3.py**: Implementación de bucles y estructuras iterativas (for, while).
* **reto4.py**: Creación y manipulación de funciones lógicas.
* **reto5.py**: Integración y resolución de problemas algorítmicos combinados.
